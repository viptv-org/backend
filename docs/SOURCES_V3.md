# Scoped native and server source integration

The native source integration invokes the pinned Rust SDK through a scoped fetcher, not a Stremio stream wrapper. The explicit real-provider qualification installs a metadata-only Stremio manifest, ignores a forged caller mapping, receives opaque SDK grants, cancels discovery and reads bounded media bytes from the retained grant. It accepts plain media signatures or AES-128 HLS with a successfully fetched 16-byte key and binary encrypted segment; this is a network/media-read check, not a decoded-frame qualification. SDK-reported presentation is additive on `SourceCandidate.presentation` (provider/source display, delivery format, declared quality/codec/audio/size). Missing fields remain null/empty; progressive delivery does not assert an MP4 container. Stremio provider display comes from the installed connection, and structured size is preserved without release-label parsing.

The SDK uses a vault-backed TMDB credential and verified canonical IMDb/TMDB identity plus explicit aired episode coordinates. Missing or conflicting mappings fail closed; labels and client hints do not become trusted identities. Native jobs resolve in the Rust process with a scoped custom fetcher. Server execution uses the same SDK/runtime behind profile assignments and opaque grants. Enabling a stream connection does not select it as the metadata owner.

`SourceCandidate.presentation` is nullable. Its fields are `provider_name`, `source_id`, `delivery_format`, `container`, `quality`, `video_codec`, `audio_codecs` (default empty), `size_bytes`, and `size_label`. They are provider-declared display fields; `provider_id` and the host-owned grant remain playback authority. Delivery format is `hls` or `progressive` when known. Codec/container/size are never inferred by client code. Stremio cards retain their existing stream name and safe structured size, with the installed provider name added separately.

This does not ban a host, infer failure from short duration, change VPN/proxy settings, or drop inconclusive 403/network responses.
